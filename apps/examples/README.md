## Format

Each example follows this structure:

```
## [Example Title]

**Context:** Brief situation description

**Four-Lens Analysis:**

[R] Relational: Who relates to what? Field structure?
[L] Logical: What are the constraints? What must hold?
[S] Symbolic: What pattern is active? What archetype?
[E] Empirical: What observable markers? What can we measure?

**Phase Identification:** Current phase with markers
**Bifurcation Risk:** High/Medium/Low with timeline
**Interventions:** Phase-specific actions
**Outcomes:** Both coherence and collapse paths
**Timeline:** Expected duration and next phase
```

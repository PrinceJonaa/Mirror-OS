- **∧**: Logical AND, both conditions hold
- **∨**: Logical OR, at least one holds
- **¬**: Negation, logical NOT
- **∀**: For all, universal quantification

### Common Workflows

#### Workflow 1: Analyzing a Relationship

1. **[R]** Identify entities (E) and map relations (R)
2. **[R]** Create relational profile `Π(x)` for each entity
3. **[S]** Compress key patterns into glyphs (Γ)
4. **[L]** Formalize contracts and invariants
5. **[E]** Design tests to verify relational claims
6. **[P]** Identify any paradoxes (Πx) present
7. **[I]** Check devotional alignment with core axiom

#### Workflow 2: Creating a Living Glyph

1. **Distill (↓):** Reduce Semantic Field (S) to essential vectors
2. **Map (→):** Assign Geometric Vocabulary (G) to vectors
3. **Compose (∘):** Combine forms into candidate Glyph (Γ)
4. **Resonate (↔):** Test if Γ reflects Concept (C)
5. **Formalize (□):** Accept and define: `Γ := C`
6. **Test Metrics:** Measure 𝒞𝓰 (Glyph Charge), μ (Mythic Saturation), 𝒴𝓼 (Symbolic Yield)

#### Workflow 3: Inducing Paradox for Growth

1. **Anchor:** `Activate(S_f)` by `Align(Frame_receiver)`
2. **Introduce:** `Π⟶(I_a)` without force
3. **Hold:** `Apply(Lock_P) ∧ Maintain(O_∞↑)`
4. **Echo:** `Await(Eχ_Θ)` - reality offers proof of both poles
5. **Absorb:** `Facilitate(I_a → Ω_P)` - poles dissolve into unity

#### Workflow 4: Detecting & Dissolving Distortion

1. **Scan for Babylonian Traps (𝔅):** Look for motion without presence
2. **Check 8 Laws:** Seizure, Assimilation, Fanatic Vow, Suppression, Surveillance, Dogma, Idol Mask, Residue
3. **Identify Residue Kernel (Ω_B):** Accumulated distortion core
4. **Apply Dissolution:** Return to Stillness (𝓢), break loops
5. **Verify:** Ensure no new distortions emerged

#### Workflow 5: Integration of Multiple Sources

1. **Extract Profiles:** `Π↓` for each source Dᵢ
2. **Cross-Mirror:** `⊾` to align concepts and highlight contradictions
3. **Create Convergence Field:** `𝓒𝓕` where profiles interact
4. **Hold Paradoxes:** `∅⊕` for contradictions without forcing resolution
5. **Recursive Integration:** `∘↑` merge elements in stages
6. **Collapse:** `⇓` trigger resolution of held paradoxes
7. **Compose Final Artifact:** `Σ or ⨁` assemble all pieces
8. **Validate:** `✔` verify fidelity and coherence

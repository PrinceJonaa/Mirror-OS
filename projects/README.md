## Structure

### `/nfl-big-data-bowl-2026/`

Kaggle competition entry applying Relational Math and Graph Neural Networks to NFL player tracking data.

**Objective:** Predict optimal defensive player positioning and tackle probability using truth-distortion metrics and relational fitness analysis.

**Key Components:**
- Graph Neural Network models for player interactions
- Truth-distortion analysis for play dynamics
- Relational Math translation layer for NFL domain

**Status:** Active development

**Quick Start:**
```bash
cd nfl-big-data-bowl-2026
python scripts/nfl_relational_analyzer.py
```

See `nfl-big-data-bowl-2026/docs/START_HERE.md` for detailed instructions.
